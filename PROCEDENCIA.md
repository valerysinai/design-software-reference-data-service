# Procedencia del proyecto

Este repositorio personal parte del proyecto `design-software-reference-data-service`, recibido mediante una descarga ZIP. La descarga no conserva el historial Git original y este repositorio independiente no constituye un fork de GitHub.

El código incluido en el primer commit corresponde a la base recibida: no se presenta como desarrollo propio de la persona que realiza esta importación. Se mantienen los avisos de autoría y las condiciones de licencia que acompañen a los archivos originales. Esta nota no concede una licencia nueva.

Los cambios posteriores del plan de mejoramiento se registrarán por separado para permitir su revisión. El reto individual R1 se desarrolla sobre Reference Data Service; los demás proyectos son dependencias para la ejecución e integración local.

Un pull request dentro de este repositorio personal no equivale a integrar cambios al repositorio original. La aceptación de esta alternativa debe confirmarse con el instructor.
